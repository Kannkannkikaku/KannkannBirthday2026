# 菅叶和さんお誕生日企画2026

声優・菅叶和さんのお誕生日（11/19）をお祝いするファン企画サイトです。
HTML / CSS / JavaScript のみで作っているので、ビルドは不要です。外部ライブラリも使っていません（フォントのみ Google Fonts を利用）。

公開URL（予定）：https://kannkannkikaku.github.io/KannkannBirthday2026/

## ファイル構成

```
index.html                  トップページ（見出し・カウントダウン・お知らせ・メッセージ縮小版）
pages/message/              お祝いメッセージ（流れる表示／一覧表示）
pages/illust/               駅広告イラスト（駅ごとのイラスト・掲出場所・イラストレーター）
pages/information/          駅広告などのお知らせ（駅ごとの掲出場所マップ・日程）
css/style.css               全ページ共通のスタイル
js/main.js                  メニュー・花びら・お知らせ・カウントダウン
js/messages.js              メッセージカードを流す処理・モーダル・一覧表示
data/messages.json          メッセージのデータ
images/stations/            駅広告イラスト・掲出場所マップ（仮画像）
images/ogp.png              SNSで共有したときの画像（1200×630、仮画像）
scripts/csv_to_json.js      CSV → JSON 変換（Node.js）
scripts/csv_to_json.html    CSV → JSON 変換（ブラウザ版・インストール不要・プレビュー付き）
scripts/sample_responses.csv 変換の練習用サンプル
```

## よく編集する場所

| やりたいこと | 編集する場所 |
| --- | --- |
| お知らせを追加する | `js/main.js` の `NEWS` 配列（上に行くほど新しい） |
| 誕生日の日付を変える | `js/main.js` の `BIRTHDAY` |
| 駅広告イラストを差し替える | `images/stations/駅広告横浜.png`・`駅広告東京.png`・`駅広告愛知.png` を同じファイル名で上書き |
| 掲出場所マップを差し替える | `images/stations/駅広告横浜マップ.png`・`駅広告東京マップ.png`・`駅広告愛知マップ.png` を同じファイル名で上書き |
| 掲出場所・日程・イラストレーター名を変える | `pages/illust/index.html`・`pages/information/index.html` の各 `station-card` |
| OGP画像を差し替える | `images/ogp.png` を上書き（1200×630px） |
| 流れる速さ・レーン数を変える | `pages/message/index.html` の `data-durations`（1周の秒数）、`data-lanes` など |
| カードの色 | `css/style.css` 冒頭の `--pink-border` などの変数 |

> ⚠ 駅広告の画像は **PNG か JPG** にしてください。PDF はページ内に画像として表示できません（スマホでは特に表示されません）。PDFで受け取った場合は、画像として書き出してから置いてください。
> JPG にする場合はファイル名の拡張子が変わるので、HTML の `src="...png"` も `.jpg` に書き換えてください。

## メッセージを追加する手順

運営が目を通してから載せられるように、**スプレッドシートの「掲載」列にチェックを入れたものだけ**がサイトに出る仕組みにしています。

```
Googleフォーム → 回答スプレッドシート → 目を通して「掲載」にチェック
  → CSVで書き出し → 変換ツールでプレビュー確認 → messages.json を上書き → push
```

### 0. 最初に一度だけ：「掲載」列を作る

1. フォームの回答先スプレッドシートを開く
2. いちばん右の空いている列の1行目に「**掲載**」と入力する（この名前ぴったりにしてください）
3. その列の2行目以降を選び、「挿入 → チェックボックス」を選ぶ

> フォームに回答が届くと行が自動で増えます。チェックボックスが付いていない行が出てきたら、上の行からコピーしてください。空欄のままでも「未チェック」として扱うので、載ってしまうことはありません。

### 1. 目を通してチェックを入れる

- 載せてよい回答だけ「掲載」にチェックを入れる
- 誤字などを直したい場合は、スプレッドシートのセルを直接書き換えてOK
- 掲載NG・重複・いたずらなどは、チェックを入れなければ載りません（行を消す必要はありません）
- チェックの代わりに `○` `OK` `済` `はい` と入力しても掲載扱いになります

### 2. CSVで書き出す

「ファイル → ダウンロード → カンマ区切り形式（.csv）」を選びます。

> ⚠ Excel で開いて保存し直すと、文字コードが Shift_JIS になって文字化けすることがあります。スプレッドシートから直接書き出したCSVを使ってください。

### 3. 変換してプレビューで確認する

**方法A：ブラウザで変換（インストール不要・おすすめ）**

1. `scripts/csv_to_json.html` をブラウザで開く（ダブルクリックでOK）
2. CSVファイルを選んで「変換してプレビュー」を押す
3. 「掲載 ○件（回答 ○件 / 未チェック ○件…）」の件数と、サイトと同じ見た目のカード一覧を確認する
4. 問題なければ「messages.json をダウンロード」を押す
5. ダウンロードしたファイルで `data/messages.json` を上書きする

> 練習用に `scripts/sample_responses.csv`（5件中3件にチェック済み）を用意しています。

**方法B：Node.js で変換**

```bash
node scripts/csv_to_json.js 回答.csv
# → data/messages.json を上書き

# 列名を指定する場合
node scripts/csv_to_json.js 回答.csv --name-col "Xのハンドル名" --message-col "メッセージ" --approve-col "掲載"
```

- 列名を指定しなければ、見出しに「ハンドル／名前」を含む列を名前、「メッセージ」を含む列を本文として自動で選びます。
- 「掲載」列が見つからないときは全件を出力し、警告を表示します。
- セル内の改行、ダブルクォート、絵文字はそのまま変換されます。
- ハンドル名に `@` がなければ自動で付けます。本文が空の行は除外します。

### 4. 2回目以降の追加

毎回**スプレッドシート全体**を書き出して `messages.json` をまるごと上書きしてください。
チェック済みの回答はすべて毎回出力されるので、前回の分が消えることはありません。
一度載せたものを取り下げたいときは、チェックを外して同じ手順をやり直します。

### 5. データの形式

手作業で追加するときも、この形に合わせてください。改行は `\n` で書きます。

```json
[
  { "id": 1, "name": "@ハンドル名", "message": "本文\n2行目" }
]
```

### 6. 公開する

手作業で追加するときも、この形に合わせてください。改行は `\n` で書きます。

```json
[
  { "id": 1, "name": "@ハンドル名", "message": "本文\n2行目" }
]
```

### 4. 公開する

`data/messages.json` をコミットして GitHub に push すると、数分でサイトに反映されます。

## ローカルで確認する方法

`fetch` で JSON を読み込んでいるため、`index.html` をダブルクリックで開く（`file://` で開く）と、メッセージが表示されません。
次のどちらかの方法で確認してください。

- VS Code の拡張機能「Live Server」を入れ、`index.html` を右クリックして「Open with Live Server」を選ぶ
- Python が入っていれば、このフォルダで `python -m http.server 8000` を実行し、http://localhost:8000/ を開く

## GitHub Pages で公開する手順

1. ファイルを GitHub に push する
   ```bash
   git add .
   git commit -m "サイトを更新"
   git push origin main
   ```
2. GitHub のリポジトリページで **Settings → Pages** を開く
3. **Build and deployment** の Source を「Deploy from a branch」にする
4. Branch を `main`、フォルダを `/ (root)` にして **Save** を押す
5. 数分後、Settings → Pages の上部に表示されるURLで公開される
   （このリポジトリなら `https://kannkannkikaku.github.io/KannkannBirthday2026/`）

> リポジトリ名やURLが変わった場合は、各HTMLの `og:url` と `og:image`（絶対URLで書いてあります）を書き換えてください。
> サイト内のリンクはすべて相対パスなので、書き換えは不要です。

## 実装メモ

- **カードの流れ方**：各レーンにカードを2セット並べ、CSS の `translateX(0 → -50%)` で無限ループさせています。1周ごとに画面外に出たセットの中身を次のメッセージに入れ替えるため、数百件あってもページ上のカードは「レーン数 × 2セット × 上限枚数」だけです。
- **一時停止**：PCではマウスを乗せたカードのレーンが止まります。カードを開いている間は全レーンが止まります。
- **動きを減らす設定**：OSで「視差効果を減らす／アニメーションを減らす」を有効にしている人には、自動スクロールをやめ、横スクロールで読める表示にしています。
- **XSS対策**：メッセージ本文や名前はすべて `textContent` で表示しています。HTMLタグが書かれていても、そのまま文字として表示されます。
